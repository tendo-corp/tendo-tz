# Открытые вопросы SCR-2a — карточка тендера (`03-screens/tender-card*.md`)

- [tender-card / права] Интерфейс карточки не прячет действия записи по праву `tenders.manage` (меню статуса, «Изменить тендер», приглашения, протокол видны любому сотруднику с доступом к карточке; отказ приходит только с сервера). Нужно ли скрывать/гасить действия по ролевой матрице? — влияет на объём работ по ролям и тест-кейсам — фронт: `TenderPage.tsx`, `TenderSummary.tsx`, `BidsTab.tsx` (проверок прав нет); сервер: `Perm("tenders.manage")` в `tenders/transport/tenders.py`.
- [tender-card-lifecycle] «Административное восстановление» завершённого/отменённого тендера упоминается в подсказке капсулы статуса и в ошибках сервера («…запрещён без административного восстановления с причиной»), но ни экрана, ни эндпоинта восстановления не найдено. Входит ли восстановление в объём? — дополнительный сценарий админа и аудит — искали в `features/tender-lifecycle`, `tenders/service/lifecycle.py`, OpenAPI.
- [tender-card-lifecycle] Кнопка «Отправить» у черновика проверяет готовность (участники, позиции, срок) только на клиенте; пункт «Сбор предложений» в меню статуса и `PATCH {status:"open"}` эти проверки не выполняют. Нужна ли серверная проверка готовности к публикации? — консистентность бизнес-правил — `TenderPage.tsx handleSendTender`, `lifecycle.py`.
- [tender-card-comparison] Определение «Потенциала» расходится: справка интерфейса (help-content `comparisonHelp.ts`) — «разница между ценой подрядчика и лучшей уже полученной сопоставимой ценой», легенда — «Запас торга: столько подрядчик готов уступить», расчёт — заявленный поставщиком `negotiation_potential` (за единицу) × объём. Какую трактовку реализовать и как поставщик заявляет запас торга? — меняет расчёт, пресет «Торги», фильтр «Есть потенциал» (≥ 50 000 ₽) — `entities/comparison/api/comparisonAdapter.ts`, `model/calc.ts`, `tenders/domain/quote.py`. На стенде запас не заявлен ни у кого (фильтр «Есть потенциал» = 0).
- [tender-card-comparison] Ставка НДС для кнопки «Вернуть на доработку: НДС» (22 %) зашита на клиенте («в данных сравнения не приходит»), в протоколе — «в т.ч. НДС 22%» с сервера. Должна ли ставка браться из настройки сервера везде? — корректность текстов и расчётов НДС — `TenderPage.tsx VAT_RATE`.
- [tender-card-comparison] Ширина столбцов колонок подрядчиков задаётся одной константой; минимальная поддерживаемая ширина окна и поведение на планшете/мобильном для СТ в коде не описаны. Нужна ли адаптивность СТ < 1280 px? — объём вёрстки — `model/columns.ts`, `TenderCompare.module.css`.
- [tender-card-structure] На стенде окно «Пересобрать разделы по ФКП» для T-2026-100 вместо плана показало «На сервере произошла ошибка…» (dry-run `POST /tenders/100/structure/rebuild?dry_run=true` → 500). Снят только экран ошибки; это дефект стенда (нет исходного файла после переноса данных?) или кода? — без плана нельзя проверить вид окна — снимок `tender-card--rebuild-sections.png`.
- [tender-card-structure / tender-card-documents / tender-card-messages] У завершённого и отменённого тендера интерфейс не блокирует правку ФКП, замену документов пакета и переписку. Так задумано или это должно быть только чтение? — влияет на правила «только чтения» — `TenderCorrectionsPanel.tsx`, `TenderDocumentsPanel.tsx` (нет проверки статуса).
- [tender-card] Требования (docs: «Рабочее место тендера») описывают кнопку «Как работает» со справочной панелью, «Пригласить в тендер» в шапке, крошки «Тендеры › год › вид работ» и постоянную правую ленту активности; в приложении этого нет (справка — только всплывающие подсказки показателей, лента — на отдельных вкладках). ТЗ написано по коду; подтвердить, что панель «Как работает» не требуется. — заметный объём (интерактивная схема, поиск по справке) — `docs/requirements/tender/README.md` §4 vs `TenderPage.tsx`.
- [tender-card-analysis] На стенде ИИ выключен: экраны «Разбор идёт», «Результат», «Разбор пары», «Ошибка», «Баланс токенов исчерпан», ответы чата и черновик письма описаны по коду без снимков. Для приёмки нужен стенд с ключом провайдера; список шагов и секций результата брался из `runPhase.ts`, `insights/service/agenda.py`, `pair.py`.
- [tender-card-participants] Кнопка «Обнулить ссылку» в строке приглашённого на ширине 1440 px при раскрытом левом меню уходит за край таблицы (на стенде не видна без прокрутки). Принять как дефект для исправления или допустимое поведение (горизонтальная прокрутка)? — `BidsTab.tsx`, снимок `tender-card--participants.png`.
- [tender-card] Снимки «Отменён», «Победитель без аккредитации», «Маска финансов» и шаг «Неодобренные контрагенты» получены подменой ответа API в браузере (на стенде нет отменённого тендера, неаккредитованных участников и пользователя-специалиста без права видеть финансы); демо-тендер «ТЗ-демо» не создавался, необратимые действия на существующих тендерах не выполнялись. Нужны ли эти состояния в демо-данных для приёмки? — полнота демо-набора.
