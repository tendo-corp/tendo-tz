# Технологический стек и допустимые замены

Какой стек у текущей реализации, что из него обязательно сохранить, а что исполнитель
может заменить без потери требований. Архитектурные требования — в
[../07-architecture/architecture.md](../07-architecture/architecture.md), деплой — в
[../08-deploy/demo-deploy.md](../08-deploy/demo-deploy.md).

## 1. Принцип выбора

Обязательны **поведение, контракты и данные**: экраны ([03](../03-screens/screen-map.md)),
HTTP API ([04](../04-api/overview.md)), модель данных ([05](../05-data-model/tables.md)),
правила бизнес-логики ([02](../02-business-logic/tenders.md)), нефункциональные требования
([07](../07-architecture/nonfunctional.md)). Конкретные библиотеки можно менять, если
сохраняются:

1. Модульный монолит с доменами и однонаправленными зависимостями (см. 07).
2. Одна реляционная СУБД PostgreSQL как источник истины, включая очередь фоновых задач
   и канал реального времени (`LISTEN/NOTIFY`). Отдельный брокер не нужен для целевых
   нагрузок (см. [scalability.md](../07-architecture/scalability.md)).
3. Аутентификация на HttpOnly-cookie (без токенов в `localStorage`).
4. Миграции схемы версионируются и применяются автоматически при старте сервиса.
5. SPA-фронтенд, статикой за обратным прокси; API на том же домене под префиксом `/api`.
6. Клиент API на фронте генерируется из OpenAPI-описания бэкенда.

## 4. Инфраструктура

| Компонент | Сейчас | Допустимая замена |
|---|---|---|
| СУБД | PostgreSQL 18 | PostgreSQL ≥ 16 (используются JSONB, `ON CONFLICT`, `LISTEN/NOTIFY`, UNLOGGED-таблицы, триггеры) |
| Хранилище файлов | любое S3-совместимое (в разработке — эмулятор s3mock, в демо — облачное объектное хранилище); альтернатива — локальный диск | MinIO, облачные S3 |
| Почта | SMTP (в разработке — перехватчик mailpit) | любой SMTP-релей |
| Антивирус вложений | опционально ClamAV (по умолчанию выключен) | — |
| Статика фронта | Caddy 2 (SPA-фолбэк, долгий кеш хешированных ассетов) | nginx |
| Обратный прокси / TLS | Traefik 3 (в разработке — локальный CA) | Caddy, nginx |
| Контейнеризация | Docker, Docker Compose | Podman |
| Оркестрация демо | PaaS для Docker Compose (класса Coolify/Dokku) | любой хостинг Compose, Kubernetes — избыточен |
| Registry | приватный registry образов (OCI) | GHCR, GitLab Registry |
| CI | GitHub Actions (сборка образов, деплой) | GitLab CI |
| ИИ | любой OpenAI-совместимый API (по умолчанию агрегатор моделей OpenRouter), модели задаются ролями | см. [../06-ai/ai-features.md](../06-ai/ai-features.md) |

## 5. Что заменить нельзя без пересмотра ТЗ

- PostgreSQL как единое хранилище, очередь задач и шина реального времени — на этом
  построены фоновые задачи, SSE и кеш тяжёлых чтений.
- Денежные расчёты в десятичной арифметике (никаких float) — см.
  [tenders-comparison.md](../02-business-logic/tenders-comparison.md).
- Инвариант ИИ «модель не выдаёт чисел, все числа проверяются по детерминированному снимку».
- Формат Excel-шаблона ФКП и загрузка КП Excel-файлом — пользователи работают с реальными
  сметами, см. [fkp-import.md](../02-business-logic/fkp-import.md).
