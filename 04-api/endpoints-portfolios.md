# API: портфели и объекты (portfolios)

Ручки страницы «Портфели и объекты» и карточки объекта: дерево «портфель → объект → подобъекты → тендеры» с поиском и фильтрами, создание, правка, перенос и архивирование портфелей и объектов. Портфели и объекты задают, кто что видит (гранты пользователей — `GET/PUT /users/{id}/access` в [endpoints-identity.md](endpoints-identity.md)), поэтому все изменения пишутся в журнал ИБ. Общие соглашения — в [overview.md](overview.md).

Связанные разделы: бизнес-логика — [../02-business-logic/portfolios.md](../02-business-logic/portfolios.md); экраны — [../03-screens/portfolios.md](../03-screens/portfolios.md), [../03-screens/object-card.md](../03-screens/object-card.md); дефолты вида работ в объекте — [endpoints-catalog.md](endpoints-catalog.md#дефолты-вида-работ-в-объекте); реестр тендеров — [endpoints-tenders.md](endpoints-tenders.md).

## Сводка

| Метод | Путь | Кратко | Доступ |
|---|---|---|---|
| GET | `/portfolios` | Дерево портфелей, объектов и тендеров с поиском | сотрудник (видит доступные объекты) |
| POST | `/portfolios` | Создать портфель | право `portfolios.manage` |
| GET | `/projects/{project_id}` | Карточка объекта: подобъекты и тендеры | сотрудник с доступом к объекту |
| PATCH | `/projects/{project_id}` | Изменить объект, перенести в другую ветку | `portfolios.manage` + доступ к объекту |
| DELETE | `/projects/{project_id}` | Архивировать объект | `portfolios.manage` + доступ к объекту |
| PATCH | `/portfolios/{portfolio_id}` | Переименовать портфель | `portfolios.manage` + грант на портфель |
| DELETE | `/portfolios/{portfolio_id}` | Архивировать портфель | `portfolios.manage` + грант на портфель |
| POST | `/projects` | Создать объект или подобъект | `portfolios.manage` + грант на портфель |

Сложность блока: **M** — дерево с правами, поиском по трём сущностям и колонками реестра тендеров (M), CRUD с проверками и аудитом (S).

## Модель и правила

- **Портфель** (`portfolios`) — группа объектов (обычно ЖК или программа); **объект** (`projects`) — стройплощадка с адресом; объекты вкладываются друг в друга произвольной глубины (`parent_project_id`), родитель — всегда в том же портфеле. Тендер принадлежит объекту.
- **Удаление — архивирование** (`is_archived`): узел навсегда пропадает из выдачи, строка остаётся (на неё ссылаются журнал ИБ и тендеры; восстановление — без бэкапа, через БД). Портфель архивируется только пустым, объект — без подобъектов и без тендеров.
- **Доступ:** администратор видит и правит всё; остальные видят объекты по грантам (на портфель — все его объекты; на объект — он, его подобъекты и путь до корня). Распоряжаться **портфелем** (переименовать, архивировать, создать в нём объект) можно только при гранте именно на портфель — доступа к одному объекту для этого мало. Править/архивировать **объект** можно при доступе к нему. Создатель портфеля (не администратор) автоматически получает грант на него.
- «Сотрудник» — роли `admin`, `tender_specialist`, `security`, `lawyer`; контрагенту — 403 «Доступно только сотрудникам компании». Отказ по праву — 403 «Недостаточно прав для этого действия — обратитесь к администратору системы».

### Объект `ProjectNode`

| Поле | Тип | Смысл |
|---|---|---|
| `id`, `name` | integer, string | |
| `address` | string \| null | адрес стройплощадки |
| `photo_path` | string \| null | ссылка на фото объекта |
| `tenders` | `PortfolioTender[]` | тендеры объекта |
| `children` | `ProjectNode[]` | подобъекты (по названию) |

### Объект `PortfolioTender` (строка реестра тендеров в дереве)

| Поле | Тип | Смысл |
|---|---|---|
| `id`, `number`, `title` | integer, string, string | номер вида `T-2026-100` |
| `work_type` / `work_type_names` / `work_type_id` | string / string[] / integer \| null | виды работ строкой через запятую и списком; устаревший одиночный вид |
| `suppliers` | string[] | названия приглашённых контрагентов (для фильтра «по контрагенту») |
| `supplier_work_types` | string[] | виды работ приглашённых (фильтр «категория поставщика») |
| `status` | string | `draft` «Черновик» \| `open` «Сбор предложений» \| `closed` «Завершён» \| `cancelled` «Отменён» |
| `custom_status_code` | string \| null | пользовательский статус ([endpoints-catalog.md](endpoints-catalog.md#статусы-тендеров-и-кп)) |
| `needs_attention` | boolean | флаг «требует внимания» |
| `responsible` | string | ФИО ответственного |
| `start`, `end` | string | даты сбора КП `YYYY-MM-DD` или `""` |
| `created_at`, `status_changed_at` | string | ISO 8601 |
| `closed_at` | string | ISO 8601 или `""` |
| `invited_count` / `responded_count` | integer | действующие приглашения / поданные КП |
| `best_price` | number \| null | итог лидера сравнения по **полным** КП; `null` без права «Цены» |
| `incomplete_min_price` / `incomplete_missing_count` | number \| null / integer \| null | минимальный итог среди неполных КП и число позиций без цены; `null` без права «Цены» |
| `deadline` | string | соблюдение срока: `on_time` «В срок», `late` «С опозданием», `overdue` «Просрочен», `""` — оценивать нечего (черновик, отменён, нет срока). Открытый тендер после даты окончания — `overdue`; завершённый — по московской дате завершения против срока |

### GET /portfolios

**Назначение.** Дерево для страницы «Портфели и объекты»: портфели → объекты верхнего уровня → подобъекты → тендеры. Поиск и фильтры выполняются на сервере.

**Доступ.** Сотрудник. Пользователю с ограниченным доступом показываются только доступные объекты; портфели без доступных объектов скрываются (у администратора пустой портфель виден). Если родитель объекта отсеян правами или поиском, объект показывается верхним уровнем своего портфеля.

**Параметры запроса:**

| Параметр | Тип | По умолчанию | Смысл |
|---|---|---|---|
| `q` | string | — | подстрока названия портфеля |
| `object_q` | string | — | подстрока названия или адреса объекта; найденные подобъекты показываются с путём до корня |
| `tender_q` | string | — | подстрока номера или названия тендера |
| `status` | string | — | статус тендера: `draft` \| `open` \| `closed` \| `cancelled` (иное игнорируется) |
| `has_tenders` | boolean | `false` | оставить только объекты (и портфели), у которых есть тендеры (с учётом подобъектов) |
| `sort` | string | `name` | порядок портфелей: `name` (по названию), `date` (новые сверху), `tenders` (по числу тендеров с подобъектами, убыв.; при равенстве — по названию) |

**Ответ `200`:** `{"items": [{"id": integer, "name": string, "projects": ProjectNode[]}]}`. Архивные портфели и объекты не отдаются. Цены в строках тендеров — только с правом «Цены».

**Ошибки.** 401/403.

### POST /portfolios

**Назначение.** Создать портфель.

**Доступ.** `portfolios.manage`.

**Параметры.** Нет.

**Тело запроса:**

| Поле | Тип | Обяз. | Ограничения |
|---|---|---|---|
| `name` | string | да | непустое после обрезки, ≤ 255 |
| `description` | string | нет | пусто — `null` |

**Ответ `201`:** `{"item": {"id": integer, "name": string}}`.

**Ошибки.** 400 «Укажите название портфеля»; 403.

**Пример.** `{"name": "ЖК «Лесной»", "description": "Вторая очередь"}` → `201 {"item": {"id": 14, "name": "ЖК «Лесной»"}}`.

**Побочные эффекты.** Не администратору — грант на созданный портфель. Журнал ИБ `portfolio_created` (имя).

### GET /projects/{project_id}

**Назначение.** Карточка объекта: сам объект с подобъектами (только доступными) и их тендерами плюс портфель, которому он принадлежит.

**Доступ.** Сотрудник с доступом к объекту.

**Параметры пути:** `project_id` — integer.

**Ответ `200`:** `{"item": ProjectNode, "portfolio": {"id": integer, "name": string}}`. Цены в строках тендеров карточки не заполняются (`best_price`, `incomplete_*` = `null`).

**Ошибки.** 404 «Объект не найден» (нет или архивный); 403 «Нет доступа к этому объекту».

**Пример.** `GET /api/projects/20` → `{"item": {"id": 20, "name": "Жилые корпуса 1 и 3", "address": "…", "photo_path": null, "tenders": [], "children": [{"id": 24, …}, {"id": 25, …}]}, "portfolio": {"id": 13, "name": "ЖК «Северный парк»"}}`.

**Побочные эффекты.** Нет.

### PATCH /projects/{project_id}

**Назначение.** Изменить объект: название, описание, адрес, фото; перенести под другого родителя в том же портфеле (или на верхний уровень). Смена портфеля не поддерживается.

**Доступ.** `portfolios.manage` + доступ к объекту.

**Параметры пути:** `project_id` — integer.

**Тело запроса** (применяются только присланные ключи):

| Поле | Тип | Правило |
|---|---|---|
| `name` | string | непустое после обрезки |
| `description` | string \| null | пусто — `null` |
| `address` | string \| null | пусто — `null` |
| `photo_path` | string \| null | пусто — `null` |
| `parent_project_id` | integer \| null | неархивный объект того же портфеля; не сам объект и не его потомок; `null` — верхний уровень |

**Ответ `200`:** `{"item": {"id", "name", "parent_project_id", "address", "photo_path"}}`.

**Ошибки.**

| Код | Когда | `detail` |
|---|---|---|
| 404 | объекта нет | «Проект не найден» |
| 403 | нет доступа | «Нет доступа к этому проекту» |
| 404 | родителя нет или он архивный | «Родительский объект не найден» |
| 400 | родитель в другом портфеле | «Родитель должен быть в том же портфеле» |
| 400 | перенос внутрь себя | «Объект нельзя перенести внутрь самого себя» |
| 400 | пустое название | «Укажите название проекта» |

**Пример.** `PATCH /api/projects/25` `{"parent_project_id": null, "address": "г. Москва, ул. Примерная, вл. 3"}` → `{"item": {"id": 25, "name": "Корпус 3", "parent_project_id": null, "address": "г. Москва, ул. Примерная, вл. 3", "photo_path": null}}`.

**Побочные эффекты.** Журнал ИБ `project_changed` (список изменённых полей).

---

### DELETE /projects/{project_id}

**Назначение.** Архивировать объект.

**Доступ.** `portfolios.manage` + доступ к объекту.

**Параметры пути:** `project_id` — integer.

**Ответ `204`** без тела.

**Ошибки.** 404 «Объект не найден» (нет или уже в архиве); 403 «Нет доступа к этому проекту»; 400 «Сначала удалите подобъекты»; 400 «Нельзя удалить объект с тендерами» (любой тендер в любом статусе).

**Пример.** `DELETE /api/projects/26` → `204`.

**Побочные эффекты.** Журнал ИБ `project_archived` (имя).

---

### PATCH /portfolios/{portfolio_id}

**Назначение.** Переименовать портфель или изменить описание.

**Доступ.** `portfolios.manage` + грант на сам портфель (администратор — всегда).

**Параметры пути:** `portfolio_id` — integer.

**Тело запроса** (только присланные ключи):

| Поле | Тип | Правило |
|---|---|---|
| `name` | string | непустое после обрезки |
| `description` | string \| null | пусто — `null` |

**Ответ `200`:** `{"item": {"id": integer, "name": string}}`.

**Ошибки.** 404 «Портфель не найден»; 403 «Нет доступа к этому портфелю»; 400 «Укажите название портфеля».

**Пример.** `{"name": "ЖК «Лесной», 2 очередь"}` → `{"item": {"id": 14, "name": "ЖК «Лесной», 2 очередь"}}`.

**Побочные эффекты.** Журнал ИБ `portfolio_changed` (изменённые поля).

---

### DELETE /portfolios/{portfolio_id}

**Назначение.** Архивировать пустой портфель.

**Доступ.** `portfolios.manage` + грант на портфель.

**Параметры пути:** `portfolio_id` — integer.

**Ответ `204`** без тела.

**Ошибки.** 404 «Портфель не найден» (нет или в архиве); 403 «Нет доступа к этому портфелю»; 400 «Сначала удалите или перенесите объекты портфеля».

**Пример.** `DELETE /api/portfolios/14` → `204`.

**Побочные эффекты.** Журнал ИБ `portfolio_archived` (имя). Гранты на портфель остаются в БД.

---

### POST /projects

**Назначение.** Создать объект в портфеле (верхнего уровня или подобъект).

**Доступ.** `portfolios.manage` + грант на портфель.

**Параметры.** Нет.

**Тело запроса:**

| Поле | Тип | Обяз. | Ограничения |
|---|---|---|---|
| `name` | string | да | непустое после обрезки, ≤ 255 |
| `portfolio_id` | integer | да | существующий портфель |
| `parent_project_id` | integer \| null | нет | неархивный объект того же портфеля |
| `description` | string | нет | |
| `address` | string | нет | ≤ 500 |

**Ответ `201`:** `{"item": {"id": integer, "name": string, "portfolio_id": integer}}`.

**Ошибки.**

| Код | Когда | `detail` |
|---|---|---|
| 400 | нет названия | «Укажите название проекта» |
| 400 | нет портфеля | «Укажите портфель» |
| 404 | портфеля нет | «Портфель не найден» |
| 403 | нет гранта на портфель | «Нет доступа к этому портфелю» |
| 404 | родителя нет / архивный | «Родительский объект не найден» |
| 400 | родитель в другом портфеле | «Родитель должен быть в том же портфеле» |

**Пример.** `{"name": "Корпус 4", "portfolio_id": 13, "parent_project_id": 20, "address": "г. Москва, ул. Примерная, вл. 4"}` → `201 {"item": {"id": 27, "name": "Корпус 4", "portfolio_id": 13}}`.

**Побочные эффекты.** Журнал ИБ `project_created` (имя, портфель).
