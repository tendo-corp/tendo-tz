# API: шаблоны тендеров

Библиотека шаблонов (`/templates`): составы ФКП, по которым регулярно запускаются однотипные тендеры. Шаблон хранит слепок в том же виде, в каком его принимает создание тендера, поэтому «сохранить из тендера» и «запустить из шаблона» — копирование без конвертации. Общие соглашения — [overview.md](overview.md); оглавление раздела тендеров — [endpoints-tenders.md](endpoints-tenders.md).

Связанные разделы: бизнес-логика — [../02-business-logic/tenders-lifecycle.md](../02-business-logic/tenders-lifecycle.md#4-шаблоны-тендеров); экраны — [../03-screens/templates.md](../03-screens/templates.md), [../03-screens/tender-create.md](../03-screens/tender-create.md), [../03-screens/tender-card.md](../03-screens/tender-card.md) («Сохранить как шаблон»); импорт ФКП и карта колонок — [endpoints-tenders-import.md](endpoints-tenders-import.md).

Сложность блока: **S** — CRUD со слепком JSON, оптимистической блокировкой по версии и аудитом.

## Сводка

| Метод | Путь | Кратко | Доступ |
|---|---|---|---|
| GET | `/templates` | Список шаблонов | сотрудник |
| POST | `/templates` | Создать шаблон вручную | сотрудник |
| POST | `/templates/from-tender/{tender_id}` | «Сохранить как шаблон» из тендера | сотрудник |
| PUT | `/templates/{template_id}` | Изменить шаблон (с проверкой версии) | сотрудник |
| DELETE | `/templates/{template_id}` | Удалить шаблон | сотрудник |
| PATCH | `/templates/{template_id}/column-map` | Запомнить подтверждённую карту колонок | сотрудник |

**Доступ — общее.** Гейт «сотрудник» (overview §3); отдельного права нет. Запуск тендера из шаблона — обычный мастер и `POST /tenders` с `template_id` (право `tenders.manage`).

**Тело — общее.** Все изменяющие ручки ждут JSON-объект: не JSON — 400 «Тело запроса должно быть JSON»; не объект — 400 «Тело запроса должно быть JSON-объектом».

## Объект `TemplateItem`

| Поле | Тип | Смысл |
|---|---|---|
| `id` | integer | |
| `name` | string | название, уникально без учёта регистра |
| `version` | integer | версия для оптимистической блокировки (растёт при каждом сохранении, с 1) |
| `source_tender_id` | integer \| null | тендер-источник («Сохранить как шаблон») |
| `createdAt` | ISO | дата создания |
| `work_type` | string | вид работ (название; один шаблон — один вид работ) |
| `sections` | array | дерево разделов: `{name, code?, unit?, quantity?, items_before?, items: [{name, unit, quantity, item_number?, budget_code?, mark?, equipment_code?, manufacturer?, attrs_json?}], children: [...]}` |
| `condition_fields` | `{field_name, field_type}[]` | доп. условия (`text`, `number`, `date`, `boolean`) |
| `column_map` | object \| null | подтверждённая карта колонок Excel (формат — `column_map` из [ParseResult](endpoints-tenders-import.md#объект-результата-разбора-parseresult)) |

Старый плоский формат слепка (`positions[]`, `conditions` строкой через «; ») читается и при первом сохранении переписывается в новый: плоский список становится разделом «Позиции шаблона».

**Правила слепка (создание и правка).** Структура нормализуется как при создании тендера: позиции без названия и пустые разделы отбрасываются. Отказы — 400: «Название шаблона обязательно»; «Вид работ обязателен»; «Добавьте хотя бы одну позицию» (после нормализации не осталось ни одной позиции). Дубль названия — 409 «Шаблон с таким названием уже есть».

### GET /templates

**Назначение.** Библиотека шаблонов, новые сверху.

**Доступ.** Сотрудник.

**Параметры запроса:** `limit`, `offset` (overview §8).

**Ответ `200`:** конверт `{items: TemplateItem[], total, limit, offset}`.

**Ошибки.** 401/403; 422.

**Пример.** → `{"items": [{"id": 2, "name": "Фасад МКД (НВФ) — типовой ФКП", "version": 1, "source_tender_id": 109, "createdAt": "2026-09-22T14:10:00+00:00", "work_type": "Устройство фасадов", "sections": [{"name": "Монтаж черновой кладки", "items": [{"name": "Кладка из газобетона", "unit": "м³", "quantity": 120}], "children": []}], "condition_fields": [{"field_name": "Условия оплаты (авансирование)", "field_type": "text"}], "column_map": null}], "total": 3, "limit": 200, "offset": 0}`

**Побочные эффекты.** Нет.

---

### POST /templates

**Назначение.** Создать шаблон вручную (экран «Шаблоны» или сохранение состава из мастера).

**Доступ.** Сотрудник.

**Тело запроса:**

| Поле | Тип | Обяз. | Ограничения |
|---|---|---|---|
| `name` | string | да | непустое после обрезки, уникально без учёта регистра |
| `work_type` | string | да | название вида работ |
| `sections` | array | да | дерево разделов (как в `TemplateItem`), ≥ 1 позиция с названием; принимается и старый `positions[]` |
| `condition_fields` | array | нет | `{field_name, field_type}`; принимается и старое `conditions` строкой |
| `column_map` | object | нет | карта колонок |

**Ответ `201`:** `{"item": TemplateItem}`.

**Ошибки.** 400 — правила слепка и формат тела; 409 «Шаблон с таким названием уже есть».

**Пример.** `{"name": "Стяжки — типовой", "work_type": "Стяжки", "sections": [{"name": "Стяжки", "items": [{"name": "Стяжка цементно-песчаная 50 мм", "unit": "м²", "quantity": 100}]}]}` → `201 {"item": {"id": 4, "name": "Стяжки — типовой", "version": 1, …}}`

**Побочные эффекты.** Журнал ИБ `template_created` (`entity_type=tender_template`, `name`).

### POST /templates/from-tender/{tender_id}

**Назначение.** «Сохранить как шаблон» из карточки тендера. Слепок берётся **из БД тендера** (разделы, позиции, доп. условия), а не из того, что нарисовал клиент.

**Доступ.** Сотрудник. Доступ к объекту тендера не проверяется (см. открытые вопросы).

**Параметры пути:** `tender_id` — integer.

**Тело запроса (может быть `{}`):** `name` — string (по умолчанию — название тендера); `work_type` — string (по умолчанию — первый вид работ тендера).

**Ответ `201`:** `{"item": TemplateItem}` с `source_tender_id`.

**Ошибки.** 404 «Тендер не найден»; 400 — правила слепка (например, у тендера нет позиций); 409 — дубль названия.

**Пример.** `POST /templates/from-tender/109` `{"name": "Фасад МКД (НВФ) — типовой ФКП"}` → `201 {"item": {"id": 2, "source_tender_id": 109, "work_type": "Устройство фасадов", …}}`

**Побочные эффекты.** Журнал ИБ `template_created` (`name`, `source_tender_id`).

---

### PUT /templates/{template_id}

**Назначение.** Изменить шаблон целиком (название, вид работ, разделы, условия, карта колонок) с оптимистической блокировкой.

**Доступ.** Сотрудник.

**Параметры пути:** `template_id` — integer.

**Тело запроса:** поля как у `POST /templates` + `version` — integer (текущая версия у клиента; если передана и не совпала — 409, проверяется **раньше** валидации содержимого). Если `column_map` не передан, сохраняется прежний.

**Ответ `200`:** `{"item": TemplateItem}` (`version` + 1).

**Ошибки.** 404 «Шаблон не найден»; 409 «Шаблон изменён в другом окне — обновите страницу»; 400 — правила слепка; 409 — дубль названия.

**Пример.** `{"version": 1, "name": "Стяжки — типовой", "work_type": "Стяжки", "sections": [...]}` → `{"item": {"id": 4, "version": 2, …}}`

**Побочные эффекты.** Журнал ИБ `template_changed` (`name`).

---

### DELETE /templates/{template_id}

**Назначение.** Удалить шаблон (физически). Тендеры, запущенные из него, сохраняют ссылку-идентификатор источника.

**Доступ.** Сотрудник.

**Ответ `204`.**

**Ошибки.** 404 «Шаблон не найден».

**Пример.** `DELETE /templates/4` → `204`

**Побочные эффекты.** Журнал ИБ `template_deleted` (`name`).

---

### PATCH /templates/{template_id}/column-map

**Назначение.** Запомнить подтверждённую на шаге 2 мастера карту колонок Excel в шаблоне («лучшее усилие»: интерфейс не блокируется при ошибке). При следующей загрузке файла с той же шапкой карта применяется молча.

**Доступ.** Сотрудник.

**Тело запроса:** `{"column_map": object}` — обязателен.

**Ответ `200`:** `{"item": TemplateItem}` (`version` + 1).

**Ошибки.** 400 «Укажите column_map»; 404 «Шаблон не найден».

**Пример.** `{"column_map": {"header_row": 11, "data_start_row": 13, "columns": [{"col": 2, "role": "name", "include": true}]}}` → `{"item": {"id": 2, "version": 2, "column_map": {…}, …}}`

**Побочные эффекты.** Журнал ИБ `template_changed` (`column_map: true`).
